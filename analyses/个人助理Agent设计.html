个人助理 Agent 设计

基于 个人方法论 和 AI与个人方法论的配合 的分析，设计一个真正匹配你认知模型的个人助理 Agent。

一、最佳实践

实践 1：口述即记录

原则依据：有记录即有能力 + 精力有限

你不应该花时间”写笔记”。最佳实践是：

  • 随时口述想法、进展、感受，哪怕一句话
  • Agent 负责整理成结构化记录，归档到正确位置
  • 你永远不需要想”这个该记在哪”

反模式：自己打开笔记软件，纠结格式和分类。这消耗的精力应该花在做事上。

实践 2：启动助推

原则依据：0.1 > 0 + 粗糙地开始 + 最简单的方法是模仿

面对新任务时，不要自己从零开始。最佳实践是：

  • 告诉 Agent 你要做什么
  • Agent 给你一个粗糙的起点（模板、草稿、拆解的第一步）
  • 你在这个起点上修改，而不是面对空白页

反模式：让 Agent 直接做完整件事。你跳过了实践环节，违反”不行则不知”。

实践 3：进展可见化

原则依据：情绪只关注当下 + 重复会降低情绪反应

大脑会低估自己的进展（因为只记得最新的）。最佳实践是：

  • Agent 主动汇总你的进展（“这周你完成了 X、推进了 Y、学会了 Z”）
  • 看板和周报不是管理工具，是给你自己看的正反馈
  • 当你觉得”什么都没做”时，Agent 用事实纠正你

反模式：只在出问题时才看记录。进展可见化的价值在于日常，不是危机时刻。

实践 4：适时拦截

原则依据：有想法就去做，做不了就别想 + 精力有限

Agent 应该识别你在”空想”还是”行动”：

  • 如果你在反复讨论一个方案但没有动手 → 提醒你”要不先做个最小版本？”
  • 如果你在一个任务上投入过多精力 → 提醒你”这个可以先到这里，够用了”
  • 如果你同时开了太多线程 → 提醒你”你现在有 3 件事在进行中，要先收掉哪个？”

反模式：Agent 无条件配合你的每一个想法，不做任何拦截。

实践 5：联想桥接

原则依据：没有联想的记忆无效 + 联想

Agent 在每次交互中主动建立联想：

  • 你提到一个新概念 → Agent 告诉你”这和你之前记录的 XX 有关”
  • 你遇到一个问题 → Agent 检索你过去类似的经历和解法
  • 你学了一个新东西 → Agent 帮你和已有知识建立连接

反模式：Agent 只回答当前问题，不做任何关联。

实践 6：复盘引导

原则依据：成了看侥幸在哪，错了看做成了哪些 + 快速失败并修正方向

Agent 在任务结束时引导双向复盘：

  • 成功时不只是庆祝，而是问”哪些是运气成分？下次能复制吗？”
  • 失败时不只是分析原因，而是问”这次做成了哪些部分？哪些可以保留？”
  • 复盘结果自动记录，成为下次决策的参考

反模式：做完就完了，不回头看。

二、Agent 角色描述提示词

三、提示词设计说明

这个提示词的设计逻辑：

为什么分四个职能而不是列一堆功能？

因为你的方法论强调”分开后就会简单”。四个职能对应四个清晰的角色，Agent 在每次交互中可以快速判断”我现在应该当记忆者、简化者、联想者还是拦截者”。

为什么有”不应该做的”？

因为你的方法论有明确的边界——“不行则不知”、“有目的但模糊结果”。如果不显式约束，AI 会倾向于”多做”，而多做恰恰违反你的原则。

为什么要用你自己的语言？

“模仿→记录→精简”——这个提示词本身就是你方法论的精简表达。用你自己的术语，Agent 的回复会自然地和你的思维框架对齐，减少翻译成本。

为什么”拦截者”是独立职能？

这是最容易被忽略但最有价值的功能。大多数 AI 助手是”你说什么我做什么”，但你的方法论明确说了”精力有限”、“做不了就别想”。一个好的助理应该在你偏离轨道时拉你一把。
